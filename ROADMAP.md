# Roadmap

## Delivered in 0.1

Curated guides, provider-neutral instructions, PR template, local Git identity/evidence checks, stale report detection and reproducible packaging. Local tests are contributor reports; no game runtime validation or trusted approval.

## Next milestones

1. Pilot the templates/preflight on representative docs, content and native changes. Measure reviewer effort and contributor friction.
2. Define maintained task/report schemas and project-owned profiles with explicit checks and environment availability.
3. Implement isolated execution with independent result collection and policy selection. Test malicious or misleading input and partial runs.
4. Add a project-owned intake check tied to exact source/base/dependency/policy identities, with agreed exceptions and outage handling.
5. If portable receipts are needed, integrate established signing plus verifier identity/policy checks. Protect signing from candidate code. Demonstrate tamper and stale-result rejection.
6. Add and test tool/provider adapters without tying the core to one model or requiring an AI subscription.

No automated merge or claim of correctness follows from admission. Maintainers decide whether to adopt the filter after a measured pilot.
