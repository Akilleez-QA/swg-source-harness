# Getting help

Start with [README.md](README.md), the [guides](docs/README.md) and
[CONTRIBUTING.md](CONTRIBUTING.md). For harness questions, reproducible defects
or proposals, use [Issues](https://github.com/Akilleez-QA/swg-source-harness/issues).
Include the harness version or full commit ID, operating system, Python and Git
versions, minimal steps, and expected versus actual behavior. Remove tokens,
private archives, local evidence paths and account data before sharing output.

For a proposal, explain the problem and intended behavior. Discuss provider
adapters, trust/signing changes and gate architecture before substantial
implementation, as [CONTRIBUTING.md](CONTRIBUTING.md) requests.

This harness is independently maintained and does not speak for SWG Source staff.
For upstream community context, see [Community and support](docs/community-and-support.md).
Questions are welcome without completing intake; this policy promises no response
time. For private contact, use [craig@nh3.biz](mailto:craig@nh3.biz).
Follow [SECURITY.md](SECURITY.md) for sensitive vulnerability reports and
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for conduct reports.
